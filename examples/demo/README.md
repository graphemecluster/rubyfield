# Rubyfield Demo

Try Mandarin Pinyin, Cantonese Jyutping, and Japanese Furigana in the [live demo](https://graphemecluster.github.io/rubyfield/).

## Launching Locally

From the repository root:

```sh
bun install
bun run dev
```

Open the URL printed by Vite. The Japanese dictionary loads when Japanese Furigana is selected.

## Development

Build the static demo with `bun run build`. See the repository's [development instructions](../../README.md#development) for type checks, formatting, and library tests.
